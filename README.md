## 🚀 Featured projects

### 📝 [ExamPortal: AI-Powered Online Exam Platform](https://github.com/YOUR_USERNAME/examportal)
Spring Boot 3 backend for creating and taking exams with auto-grading and AI-generated explanations for wrong answers.
- **Auth:** Spring Security 6, JWT access tokens + HttpOnly-cookie refresh token rotation, role-based access (Admin / Student)
- **Data:** PostgreSQL with Flyway migrations, fully containerised with Docker Compose
- **AI:** Gemini-powered "AI Insight" that explains the correct answer on missed questions
- `Java` `Spring Boot` `Spring Security` `PostgreSQL` `Flyway` `Docker`

### 🤖 [AI Code Review Bot](https://github.com/YOUR_USERNAME/ai-code-review-bot)
Listens to GitHub pull requests and posts AI-generated review comments automatically.
- GitHub webhooks verified with **HMAC-SHA256** signatures
- Moved processing to a **BullMQ + Redis** job queue, which eliminated webhook timeout failures and improved processing efficiency by ~20%
- Live **React** dashboard (Socket.io + Recharts) showing review activity in real time
- `Node.js` `Express` `BullMQ` `Redis` `Gemini API` `React` `Socket.io`

### 📚 [Lumen: Local-First Document Q&A](https://github.com/YOUR_USERNAME/lumen)
Ask questions over your own documents without sending them to a third party. Fully local RAG pipeline.
- Chunking, embeddings and vector retrieval served through **FastAPI**
